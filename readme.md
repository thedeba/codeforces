## 🛠️ How to Compile & Run

### Using `g++`:

```bash
# Compile
g++ -std=c++17 -O3 <filename>.cpp -o output/<filename>

# Run
./output/<filename>
```

### Using `clang++`:

```bash
clang++ -std=c++17 <filename>.cpp -o output/<filename>
./output/<filename>
```

**Example:**
```bash
g++ -std=c++17 110A.cpp -o output/110A
./output/110A
```
