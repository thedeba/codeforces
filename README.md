## 🛠️ How to Compile & Run

### Using `g++`:

```bash
# Compile
g++ -std=c++17 -O3 <filename>.cpp -o <filename>

# Run
./<filename>
```

### Using `clang++`:

```bash
clang++ -std=c++17 <filename>.cpp -o <filename>
./<filename>
```

**Example:**
```bash
g++ -std=c++17 469A.cpp -o 469A
./469A
```
